# HDU-Lolita爱好站 · 站点简介与使用说明

欢迎来到 **HDU-Lolita爱好站**，这是一个以 Lolita 服饰文化为主题的轻量级展示与交流网站，主要面向对 Lolita 感兴趣的同学和访客。

---

## 1. 站点简介

- **主题定位**：Lolita 服饰文化图鉴 + 简单的贩售信息整理 + 轻社交互动。
- **视觉风格**：以粉白、蕾丝、复古优雅为主的 Lolita 美学风格。
- **适用人群**：杭电及周边高校的 Lolita 爱好者、对该文化感兴趣的同学和访客。

本网站为 **前端静态站点**，主要用于展示与体验，暂不提供真实在线交易功能。

---

## 2. 页面与功能一览

### 首页（index.html）
- 展示网站标题、横幅 Banner 和部分精选内容预览。
- 可以快速跳转到“关于 Lolita”“贩售信息”“留言区”等主要功能页。

### 关于 Lolita（pages/about.html）
- 简要介绍 Lolita 时尚的来源、常见款式（JSK / OP / SK）及基础穿搭结构。
- 帮助第一次接触该文化的访客快速了解基本概念。

### 贩售信息（pages/sales.html）
- 以表格 + 卡片形式列出部分示例 **Lolita 系列** 的：
	- 系列名称、品牌
	- 定金时间区间
	- 当前销售状态（定金中 / 已结束 等）
- 可点击“查看详情”进入 **商品详情页**（pages/sales-detail.html），查看更完整的文案与搭配建议。

### 商品详情（pages/sales-detail.html）
- 针对单个系列展示：图片、品牌、风格、定金/尾款时间、简介与搭配小提示。
- 页面底部会推荐“你可能也喜欢”的其他示例系列，方便继续浏览。

### 留言区（pages/message.html）
- 提供一个 **前端表单**，用于演示“昵称 + 主题 + 内容”的留言提交流程。
- 当前版本仅为 **演示效果**：
	- 提交后会弹出提示，但不会把留言发送到服务器。
	- 刷新页面后不会保留之前填写的内容。

### README 页面（pages/readme.html）
- 将本文件（README.md）的内容以 Markdown 渲染的方式展示给访客。
- 用于帮助第一次访问本站的人快速了解站点结构和使用方式。

---

## 3. 使用说明（给访客）

### 3.1 导航与浏览

- 顶部导航栏始终可见，包含：`首页 / 关于Lolita / 贩售信息 / 留言区 / README`。
- 任意页面都可以通过导航快速切换到其他页面，无需返回首页。

推荐使用方式：
1. **从首页进入**，感受整体风格。
2. 打开 **“关于 Lolita”** 了解基础概念。
3. 在 **“贩售信息”** 中查看示例系列设计与时间节点。
4. 如有想法，可在 **“留言区”** 写下建议或感受（演示提交）。
5. 在 **“README”** 页面快速回顾站点功能说明。

### 3.2 登录昵称（导航右上角）

- 右上角会显示一个 **登录按钮**：
	- 点击后可以输入一个昵称（例如：`Yue`）。
	- 昵称会保存在浏览器的 `localStorage` 中，仅在本设备、本浏览器生效。
- 登录后：
	- 导航中会显示形如 `@Yue` 的用户昵称。
	- 可以点击“登出”按钮清除本地昵称。
- 注意：
	- 这只是一个前端演示的“轻量登录”，不会创建真实账户，也不会上传到服务器。
	- 请不要在昵称中填写任何敏感个人信息。

### 3.3 留言区使用提示

- 表单字段说明：
	- **昵称**：在页面中展示的称呼，用于区分不同留言者。
	- **邮箱（可选）**：仅作展示，不会发送邮件。
	- **主题**：可选择“网站建议 / 穿搭分享 / 贩售咨询 / 其他”等分类。
	- **留言内容**：用于填写建议、想法或简单的穿搭心得。
- 隐私提示：
	- 本站不做真实数据存储处理，但依然建议 **不要填写学号、手机号等隐私信息**。

## 4. 对开发者 & 课程老师的说明（简要）

- 本站为 **纯前端静态项目**：
	- 页面使用 HTML + CSS + 少量 JavaScript 实现。
	- 使用 `fetch` 动态读取根目录下的 `README.md`，并通过 `marked` 库进行 Markdown 渲染。
- 主要脚本文件：
	- `js/auth.js`：演示基于 `localStorage` 的昵称登录/登出逻辑。
	- `js/products.js`：集中管理示例贩售商品数据和状态标签。
	- `js/readme.js`：读取并渲染本 README，使访客可在浏览器中阅读站点说明。

如果你有任何改进建议，欢迎在“留言区”页面留下想法（尽管目前仅为演示），也可以在本项目仓库中直接进行二次开发与美化。 :)
